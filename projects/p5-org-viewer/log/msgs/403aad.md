1. 未読: 受け箱は、未読の件を種類・本文の有無にかかわらず先頭の側（読むもの）に出す。本文なしの done は「（完了の知らせ・本文なし）」。畳みは「既読の完了通知 N 件」だけ。一覧の「未読」の数字とプロジェクト行のバッジは受け箱へのリンク（1 クリック）。
2. 「いま／最後」: lifecycle と本文なしの done を使わず、最後の message。閉じたプロジェクトは user 宛ての最後の report を優先。一覧は 60 字で 1 行、プロジェクトの中は先頭カードと、時系列の該当 report が開いた状態で本文が読める（p3: 「p3-org-visibility の結果」）。
3. 時系列: プロジェクトの層（PM・user・auditor）の行だけ並べ、チームごと（timeline-tool 12 件・readme-guide 7 件）は `<details>` に畳む。本文なしの done は行にせず件数だけ（8 件）。
