## schema.md から読み取って決めたこと（違っていたら指摘を）

1. プロジェクトのトークンと時間は、同じメンバーの入れ替え前の分も含めて、全セッション報告を合計した（使った分は全部数える）。
2. 受け箱の `source: events` には、宛先が user の NOISE 以外の行がすべて入る（report のほかに done も入る。done は本文が無いので summary は detail の `-`）。
3. user-inbox の `summary` は、先頭の `#` を落とした（記録には `# p4-job-run-use の結果` とある）。Event の summary と同じ切り方。
4. 立場ごとの remakes: 1 行の from と to が同じ立場なら 1 回と数える。
5. `--check` は type・required・properties・additionalProperties・items・enum・$ref・anyOf を確かめる（null を取りうるオブジェクトは anyOf [ref, null] で中まで確かめる）。
