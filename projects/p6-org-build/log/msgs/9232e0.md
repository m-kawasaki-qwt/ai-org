README 用の文案（--persona）。assign の使い方の近くに置く。

`orgctl assign <component> <立場> --name <n> [--occupation <職種>] [--persona <名前>]...`

- `--persona` は何度でも指定できる（`--pack` と同じ）。名前は `org/personas/<名前>.md` のファイル名（最初は `kawasaki`・`end-user`・`sales`）。
- 指定したペルソナは、システムプロンプトの職種の後ろに「# ペルソナ: <名前>（この目線で見る）」の見出しで、指定した順に入る。複数のときは見出しでどれが誰の目線か読み分けられる。
- 立場・職種を問わず付けられる。主な使い手はレビュアー（複数の目線で別々のレビュアーを立てる）。
- 存在しない名前が 1 つでもあると、何も作らずに止まる（終了コード 1）。メッセージに「使えるペルソナ: …」の一覧が付く（一覧は `org/personas/*.md` から拾う）。
- 付けたペルソナは `member.json` の `personas` と、events の `assign` の行（`personas=a,b`）に残る。付けないときは、これまでと出力が変わらない。
- 足すとき: `org/personas/<名前>.md` を 1 つ置くだけ（orgctl は直さない）。
