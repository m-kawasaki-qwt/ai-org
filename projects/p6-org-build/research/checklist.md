## 撮り方

- 画面ごとに、**幅 900px と 1800px の 2 枚**をページ全体で撮る（ダークモードの状態で）。
- 状態の分も撮る: 開閉を 1 つ開いた状態／Tab を数回押してフォーカスがある状態。押せる要素の `cursor`（computed style）は Playwright で読み、撮った画像と一緒に残す（C-19）。
- コントラスト比は目で決めず、画素の色から測る（例: `tools/png_contrast.py <png> x0 y0 x1 y1`。標準ライブラリだけで、矩形の中の背景色と最も離れた文字色の比を出す）。

| B-04 | 画面ごとに、スクロールせずに掴ませたい要点（1〜3 個）を決め、それをいちばん目立たせると決めたか | V-01, V-04, D-02 |

## C 画面を撮って確かめること

答え方: 撮った画像（と撮影時に一緒に取った値）だけを見て、はい／いいえ。その画面にその要素が無ければ「対象外」。

**色・コントラスト**

| 番号 | 問い（はい＝合格） | 参照 |
|---|---|---|
| C-01 | 全画面で、ページの背景が暗い色（真っ黒 #000 ではない濃いグレー）か | K-02, K-04 |
| C-02 | いちばん薄い文字（補足の灰色を含む）と背景のコントラスト比が、画素で測って 4.5:1 以上か | A-01, K-01 |
| C-03 | グラフの棒・線・帯や、意味を持つ図形と隣の色のコントラスト比が 3:1 以上か | A-02 |
| C-04 | 状態（開いている・閉じた・未読 など）を、色だけでなく文字か形でも区別しているか | A-03 |

**要点と階層**

| 番号 | 問い（はい＝合格） | 参照 |
|---|---|---|
| C-05 | 900px 幅でスクロールせずに見える範囲に、その画面の要点が「判断か行動につながる形」（「◯◯が要る」「◯◯は問題なし」「◯件が判断待ち」）で出ているか（合計の数字が並ぶだけは いいえ） | D-01, D-02, V-04, H-01 |
| C-06 | 画面をぼかして（目を細めて）見たとき、いちばん目立つ要素が、その画面の要点（B-04）か | V-01, D-03 |
| C-07 | 文字の大きさが 3 段程度（見出し・小見出し・本文）に収まり、見出しが本文より大きいか太いか | V-01 |
| C-08 | Markdown・YAML の記号（行頭の `#`・`**`・バッククォート・`key: value` の字下げ）が、整形されずにそのまま見えていないか | H-02, A-07 |
| C-09 | 画面の主な部分が、元の記録の 1 件＝1 行を時刻順（ファイル順）に並べただけになっていないか（まとめた数字・要約・図のどれかが主か）。1 件ずつ読むこと自体が目的だと B-01 に書いてある画面（受け箱など）は対象外 | P-03, D-01, D-03, G-01 |
| C-10 | 誰と誰のやりとり・入れ子のような関係（B-05 で関係を見せると決めたもの）が、文中の「A → B」ではなく、帯・線・入れ子の配置で見えるか | P-03, V-02, G-02 |

**一覧・表・数字**

| 番号 | 問い（はい＝合格） | 参照 |
|---|---|---|
| C-11 | 表・一覧のセルで、日時・数値・状態・名前が 2 行以上に折り返していないか（900px と 1800px の両方で） | G-03, R-01 |
| C-12 | 一覧（表の行・畳んだ行）のセルに、2 文以上の文章や全角 40 字を超える説明文が入っていないか | W-01, W-03, P-01, H-05 |
| C-13 | 表の各列が 1 種類の値だけを持ち、列見出しがその値の名前になっているか（1 列に「出来事」と「時刻」など 2 種類を混ぜていない） | G-03, H-04, W-02 |
| C-14 | 数値の列が右揃えで、同じ列の単位・桁がそろっているか | G-04, D-03 |
| C-15 | 大きく出した数字（カード）に、比べる相手（目標・前回・平均・上限）か良し悪しの判断が添えられているか | D-03, D-01 |
| C-16 | 見出し・行の頭が、内部の ID・パス・種類のコード（`report`・`p3-…/pm`・ファイルパス・時刻）ではなく、中身を言う語で始まっているか（使う人がその名前で呼んでいるもの＝プロジェクトの名前などは可） | V-03, W-02, H-02 |
| C-17 | クリックできる文字・要素が、本文と違う色に加えて下線・ボタンの形・▶ の印のどれかを持ち、クリックできないものは同じ見た目をしていないか（押せるカードと押せないカードが同じ見た目、は いいえ） | F-01, F-02, F-03, A-03 |

**操作の手がかり**

| 番号 | 問い（はい＝合格） | 参照 |
|---|---|---|
| C-18 | 開閉できる行に、閉じているとき ▶・開いているとき ▼（または ＋／−）の印があり、行全体が枠か背景で 1 つの押せる形になっているか | F-05, P-02 |
| C-19 | 押せる要素（リンク・開閉の行・ボタン・押せるカード）の `cursor` が `pointer` か（撮影時に読んだ値で答える） | F-04 |
| C-20 | Tab で移ったフォーカスの位置が枠や下線で見え、固定の要素に隠れていないか | A-04, A-05 |
| C-21 | 押せる要素の高さ・幅が 24 CSS px 以上か（文中のリンクと、周りに 24px 以上の間隔があるものは除く） | A-06 |

**幅・文章**

| 番号 | 問い（はい＝合格） | 参照 |
|---|---|---|
| C-22 | 900px と 1800px の両方で、横スクロール・要素の重なり・はみ出し・背景の途切れが無いか | R-01, R-02, V-02 |
| C-23 | 1800px で、文章のかたまりの 1 行が全角 40 字（欧文 80 字）程度に収まっているか | A-08, R-03 |

**開閉・グラフ・一貫性**

| 番号 | 問い（はい＝合格） | 参照 |
|---|---|---|
| C-24 | 開閉の入れ子が 2 段以内か | P-01, P-02 |
| C-25 | 畳んだ行の見出しだけで、中身の要点（結論か件数）が分かるか | P-01, P-02, W-02 |
| C-26 | グラフで、量を棒の長さ・位置で表し、円・3D・色の濃さで量を表していないか | D-04, G-02 |
| C-27 | 同じ種類の要素（状態の名前とバッジ・日時・数値の書式）が、全画面で同じ言葉・同じ見た目か | H-03 |

## 当ててみて直したこと

- **C-05**: 最初は「要点が最上部にあるか」だった。④ の「全体: トークン 56.52M・往復 13・作り直し 6」が要点かで迷ったので、「判断か行動につながる形か（合計の数字が並ぶだけは いいえ）」にした。
- **C-09**: ③ 受け箱は 1 件ずつ読む画面で、時刻順の一覧そのものは悪くない。一律に いいえ にせず、B-01 にそう書いてあれば対象外とした。
- **C-16**: フィードバックで「プロジェクトの名前はよい」と言われている（`p5-org-viewer` のような名前）。使う人がその名前で呼ぶものは可、と除外を足した。
- **C-17**: ① ⑤ のカードが押せるかどうかを、画像からは答えられなかった。答えられないこと自体が手がかりの不足なので、「押せるものと押せないものが同じ見た目なら いいえ」と問いに入れた。
- **C-19・C-20**: カーソルの形とフォーカスはスクリーンショットに写らない。撮るときに一緒に取る値・状態として「撮り方」に入れた。
